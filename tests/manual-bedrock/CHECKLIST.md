# 実機テスト合否チェックリスト

試験ごとにこのファイルをコピーして記入してください。手順の背景と安全上の注意は [README.md](README.md) を参照します。

> **未検証機能を「動作確認済み」にしないための記録です。** `resource_pack/` にはテンプレート（`manifest.json`、`ui/invui.json`、`ui/_ui_defs.json`）があり、CLI の `--install-resource-pack` で既存 Resource Pack へ `ui/invui.json` だけを追加できますが、どの画面にも接続されておらず実機未検証です。`invui_probe` を参照するテスト画面とテスト用アダプタが揃うまで、`ENV-*` と `BASE-*` 以外は「未実施」のまま残してください。実施は使い捨てワールドだけで行ってください。
>
> `button.send` を単独で観察する [`button-send-resource-pack/`](button-send-resource-pack/README.md) は**使い捨てワールド専用**の別キットです。クリック通知は未検証で、通知文字列を自動設定する仕組みはなく、入力抑制・アイテム保護もありません。**他の Resource Pack との併用は禁止**です。このキットを導入しただけでは `CLICK-*` を実施済みにしないでください。

## C. アイテム保護（表示専用・ボタン用スロット）

**表示専用アイテムが 1 つでも持ち出せたら不合格。** 現行コアは表示アイテムを `setItem()` で置くだけで保護がないため、取り出し＋再描画による複製も試します。合格するまで D へ進まない。

| ID | 手順 | 合格条件 | 結果 | 根拠・メモ |
|---|---|---|---|---|
| PROT-01 | PC で表示専用アイテムをクリック、Shift クリック相当、ドラッグ、ダブルクリック相当、ドロップする | アイテムが移動・消滅・複製しない | | |
| PROT-02 | タッチでタップ、長押し、ドラッグ、ダブルタップ相当を行う | 同上 | | |
| PROT-03 | コントローラーでカーソルを合わせ、決定・ドラッグ相当・ドロップ相当を行う | 同上 | | |
| PROT-04 | 操作前後で保管領域と画面内の個数を数える | 合計個数が一致し、複製・消失がない | | |
| PROT-05 | ボタン用スロットと表示専用スロットを混ぜた画面で同様に操作する | ボタン以外のアイテムが動かない。ボタン押下でアイテムが消費されない | | |
| PROT-06 | 表示専用アイテムを取り出した後に、状態更新や `refresh()` で再描画させる | 同じアイテムが再設定されて複製しない。複製・消失したら即時中止 | | |

## D. クリック通知

入力経路が利用可能な場合だけ実施します。`button.send` → チャット通知は候補であり、チェスト画面で成立するかは未確認です。成立しない場合は「不合格」として記録し、別方式を検討します。

`button.send` の観察だけを行う場合は、[`button-send-resource-pack/`](button-send-resource-pack/README.md) を**使い捨てワールドで単独使用**します。このキットは陽性対照ラベルと押下用ボタンを差し込むだけで、**通知文字列を自動設定する仕組みはなく**、入力抑制・アイテム保護もありません。他の Resource Pack との併用は禁止です。ラベルやボタンが出たこと、押下で見た目が変わったことは、CLICK-* の合格ではありません。

| ID | 手順 | 合格条件 | 結果 | 根拠・メモ |
|---|---|---|---|---|
| CLICK-01 | PC でボタン用スロットを 1 回クリックする | Script API 側の通知が 1 回だけ届く | | |
| CLICK-02 | タッチで 1 回タップする | 同上 | | |
| CLICK-03 | コントローラーで 1 回決定する | 同上 | | |
| CLICK-04 | 通知からプレイヤーとスロット番号を特定する | 実際に押したプレイヤー・スロットと一致する | | |
| CLICK-05 | ページ・タブを変更した直後に、変更前のスロットを押す | 古い世代の通知が実行されない | | |
| CLICK-06 | 画面を閉じた後に、遅れて届く通知を発生させる | 閉じた Window のハンドラーが実行されない | | |
| CLICK-07 | クリック後のチャット欄を確認する | 通知文字列が通常チャットとして表示されない | | |
| CLICK-08 | 同じ通知を連続送信・再利用する | 現在の Window・状態と照合され、重複実行されない。セッション ID だけを認証に使わない | | |
| CLICK-09 | 表示専用または `inventory` スロットを `button` として通知する | ユーザーハンドラーが実行されない | | |

> CLICK-* が不合格の場合、クリック機能を「提供済み」として README やリリースノートに書かない。

## E. `InventoryLink` の安全試験（`C` 合格後に最後に実施）

使い捨てアイテムだけで実施します。設計書の安全条件（移動の整合、複製防止、カーソル・プレイヤーインベントリ・VirtualContainer の検査、離脱後の補充禁止）を確認します。

| ID | 手順 | 合格条件 | 結果 | 根拠・メモ |
|---|---|---|---|---|
| INV-01 | リンク元から GUI へ、GUI からリンク元へアイテムを移動する | 移動前後の個数が一致する | | |
| INV-02 | リンクされたスロットでドラッグ操作を行う | 途中状態でも複製・消失しない | | |
| INV-03 | カーソルにアイテムを持った状態で画面を閉じる | アイテムが消えない。リンク元と重複しない | | |
| INV-04 | 移動中に死亡・ディメンション移動・切断を発生させる | 未確定移動が安全側に処理される。複製しない | | |
| INV-05 | 同じリンク元を複数 Window で表示し、片方で変更する | 他の表示中 Window にも反映され、表示が食い違わない | | |
| INV-06 | リンク元のインベントリ内容を外部から変更する | GUI 表示がリンク元に追従する | | |

> 複製・消失が 1 件でもあれば中止し、`InventoryLink` を無効のままにする。
